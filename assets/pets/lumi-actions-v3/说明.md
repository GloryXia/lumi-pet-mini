# 露米 · 动作增强版

转圈跳新增冰蓝紫色环绕光带、弧形轨迹和局部光晕。效果随转身变化，背景仍然透明，没有底色和背景框。

同时包含上一版的待机眨眼/轻微歪头、问候挥手比心。既有任务状态动画与 16 个视线方向保留。

触发方式：鼠标悬停 → 转圈跳；问候提示 → 挥手比心；待机 → 眨眼/歪头。动作触发沿用 App 现有规则，当前没有自定义随机动作池或定时播放频率的接口。

本机原生 App 的设置 → Pets 中刷新，必要时重新选择“露米 Lumi”。本次未更新云端宠物。

`spritesheet-before-update.webp` 是本机更新前的动画图，可用于回退。

制作使用内置 imagegen。完整视觉提示词见“制作提示词.md”。
