# 露米 Lumi · 动作更新

新增：待机眨眼和轻微歪头、问候挥手后双手比心、鼠标悬停时转圈跳。

保持透明背景、无底框。宠物 ID 和名称保持不变。已有任务动画和 16 个视线方向逐像素保留。

## 原生 App 的触发方式

| App 状态/交互 | 动画槽位 | 本次包的表现 |
| --- | --- | --- |
| 没有任务状态提示 | idle | 眨眼、轻微歪头 |
| 问候提示 | waving | 挥手、双手比心 |
| 鼠标移到宠物上 | jumping | 转圈跳 |
| 任务运行中 | running | 原有专注思考动作 |
| 需要输入/批准 | waiting | 原有期待动作 |
| 完成结果尚未查看 | review | 原有查看/思考动作 |
| 失败或受阻 | failed | 原有低落动作 |

App 使用固定动画槽位，当前没有可供自定义宠物设置随机动作池或定时频率的接口。此包未增加随机调度器，也未修改 App 程序。

特效可以画入任务状态动画中，在对应状态出现时跟随播放。当前动作更新没有另加任务特效；后续可分别设计运行、等待、完成待查看、受阻的效果。所有效果必须留在每帧的透明区域内，尺寸适合原生宠物。

## 刷新

在 App 的设置 → Pets 中刷新；必要时重新选择“露米 Lumi”。更新的是本机原生宠物文件，不会同步更改云端宠物记录。

## 回退

`spritesheet-before-update.webp` 是更新前的精灵图；可用它替换本机 `~/.codex/pets/lumi/spritesheet.webp` 后刷新。
